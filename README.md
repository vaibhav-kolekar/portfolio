# Vaibhav Kolekar — Portfolio

Live site: https://vaibhav-kolekar.github.io/portfolio/

A premium, responsive, accessible, zero-build static portfolio. Based on the attached professional resume. No paid services, backend, Node.js, dependencies, or API keys required.

## Preview locally

Open `index.html` in a browser. Or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

## Publish for free with GitHub Pages

1. This site lives in the public repository `vaibhav-kolekar/portfolio`.
2. Upload the **contents** of this folder (`index.html`, `styles.css`, `script.js`, `assets/`, etc.) to the **root** of the repository. You can use GitHub's **Add file → Upload files**.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
5. Once deployment finishes, visit `https://vaibhav-kolekar.github.io/portfolio/`. Publishing may take a few minutes.

Alternatively, place these files at the root of any public repository and enable Pages; the URL will be `https://vaibhav-kolekar.github.io/REPOSITORY-NAME/` (this repo: `/portfolio/`).

## Customize

- Edit content, links and sections in `index.html`.
- Edit theme colors in `styles.css` (`:root` CSS variables).
- Replace `assets/resume.pdf` when your resume changes.
- Update the contact and social URLs in `index.html` if needed.
- For a custom domain, configure it in **Settings → Pages → Custom domain** and set DNS at your domain registrar.

## Notes

- The website intentionally does not invent personal projects, certifications, employer logos, or client endorsements.
- The resume contains your email and phone number. The site itself displays email publicly and provides the full PDF for download; remove or redact the phone number in `assets/resume.pdf` if you do not want it publicly accessible.
- Google Fonts are loaded from Google's CDN; the rest of the site works without third-party dependencies.
- This is static hosting; contact uses `mailto:` and needs no server.
